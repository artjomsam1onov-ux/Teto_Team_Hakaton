# Teto Team Hakaton  MVP анализа обращений граждан

## Описание

Проект реализует MVP-pipeline для автоматического анализа обращений граждан Омской области с использованием локальной open-source LLM.

Основная задача: из Excel-файла с обращениями выделить реальные проблемы, сгруппировать их по муниципалитетам и темам, а затем сформировать Excel-отчёт и краткую текстовую справку.

## Что делает решение

Pipeline выполняет следующий сценарий:

1. Читает Excel-файл с обращениями.
2. Извлекает текст обращения из колонки `Текст инцидента`.
3. Классифицирует обращение как `проблема` или `не проблема` через локальную LLM Ollama + Llama 3.2.
4. Применяет правила постобработки для стабильной классификации.
5. Группирует найденные проблемы по муниципалитетам, группам тем и темам.
6. Формирует Excel-отчёт.
7. Формирует краткую текстовую справку.

## Стек

- Python
- pandas
- openpyxl
- requests
- Ollama
- Llama 3.2 3B

## Основные файлы

- `pipeline_main.py` — основной pipeline для запуска на prod-датасете.
- `pipeline_organizer.py` — версия pipeline для тестового датасета организаторов.
- `inspect_dataset.py` — проверка структуры Excel-файла.
- `requirements.txt` — зависимости Python.
- `.gitignore` — исключения для временных, больших и системных файлов.

## Как запустить

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Установить Ollama

Скачать и установить Ollama: https://ollama.com/download

После установки скачать модель:

```bash
ollama pull llama3.2:3b
```

### 3. Положить Excel-файл рядом со скриптом

Основной файл должен называться:

```text
ИМ_29_05_2026_prod(1).xlsx
```

### 4. Запустить основной pipeline

```bash
python pipeline_main.py
```

## Результаты запуска

После выполнения появятся файлы:

- `Excel_результат.xlsx` — Excel-отчёт с классифицированными обращениями и агрегатами.
- `Итог.txt` — краткая текстовая справка.

## Текущий результат MVP

В тестовом запуске обработаны первые 500 обращений prod-датасета.

Результат:

- обработано обращений: 500;
- выявлено потенциальных проблем: 496;
- основной муниципалитет по количеству проблем: Омск г.о.;
- самая частая тема: дороги / уборка дорог от снега и наледи.

Высокая доля проблемных обращений связана со спецификой входной выгрузки и будет дополнительно валидироваться на следующих этапах.
